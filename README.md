# japan-travel-guide

2026년 11월 중·하순, 3박 4일 일본 지역별 여행 가이드 웹 화면.

규슈(다자이후·유후인·벳푸) · 오키나와 본섬 · 미야코지마 · 이시가키지마 · 도쿄 · 삿포로

## 화면
- **메인** `#/` — 여행 기간 선택(중순 11/12~15 / 하순 11/26~29 / 직접), 공통 안내(면세 환급 방식, 연휴), 지역 카드
- **상세** `#/r/{id}` — 지역 정보, Day 탭, 시간순 일정 카드, 기간 체크·이동 팁·내 일정 추가·진행률
  - 도쿄 Day 3은 당일치기 코스 선택: 시즈오카 / 가마쿠라 / 가와고에 / 도쿄 시내
  - 추천 항공편(인천 기준, 귀국 20시 이전 도착), 추천 숙소 위치
- **레이어 팝업** — TIP(영업시간·휴무·주의·참고·구글 지도·공식 링크), 전체 일정 요약

## 파일
- `index.html` / `style.css` / `app.js` — 빌드 없는 정적 웹앱 (GitHub Pages)
- `data.js` — 지역·일정·TIP 데이터 (`REGIONS`, `COMMON_NOTES`, `CHECKED_AT`)
- `memos.js` — 일정별 "할 수 있는 것" 메모

사용자 상태(여행 기간, 체크, 내 일정)는 브라우저 `localStorage`에 저장되며 상단 "초기화"로 되돌립니다.
정보 확인일은 `data.js`의 `CHECKED_AT`이며, `verified: true` 항목만 웹 검색으로 확인한 정보입니다.
